# PacMan 3D
Проект реализован на C++14 в Unreal Engine 4.27 с использованием Visual Studio 2019.
Нужно собрать все пилюли в лабиринте и не попасться призракам. За каждую пилюлю начисляется 10 очков. 
При столкновении с призраком игра заканчивается.

Лабиринт генерируется заново при каждом рестарте. У трёх призраков разное поведение.

Управление – WASD или стрелки. Выход – Alt + F4.
